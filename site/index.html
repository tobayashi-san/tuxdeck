01 Everything a deck should do

It feels like the official app: drag an action onto a key, done. The rest is made for Linux, not ported to it.

All the usual keys

Folders, pages, profiles, multi actions, Key Logic, hotkeys, text snippets, a soundboard, timers and media keys.

Your plugins keep working

Plugins for the Stream Deck SDK run unmodified, settings pages included. A catalogue installs open-source ones with one click.

Bring your setup along

Profiles and backups from the official app import as they are. Keys pointing at Windows or macOS programs get converted for Linux.

A Linux check for plugins

Every plugin gets test-run in an isolated instance, and a badge tells you whether it really works on Linux.

Hotkeys that land

Your keyboard layout is respected, and on Hyprland a hotkey that's one of your own bindings simply runs it.

Profiles follow your focus

Open your editor, get your editor keys. On Hyprland, KDE Plasma and X11 profiles switch with the window in focus.

Good looking keys

Elgato's open icon set built in, gradients, icon colours, and four ready-made profiles in one calm design.

Neo info bar & dials

Clock, page dots or your own text on the Neo's info bar; dials and the touch strip on the Stream Deck +.

02 Bring your deck

Mini, Neo, MK.2, Stream Deck + (dials and touch strip), XL, Pedal and the first-generation models.

The Neo and the MK.2 run on real hardware every day; the others are tested against simulated devices. Not yet: Stream Deck Studio, the modules and the Mini Discord edition. Own one? A quick report helps a lot.

03 Install in a minute

Grab the package for your system from the latest release, then:

$ sudo apt install ./tuxdeck_*_amd64.deb
$ systemctl --user enable --now tuxdeck
$ sudo dnf install ./tuxdeck-*.x86_64.rpm
# openSUSE: sudo zypper install --allow-unsigned-rpm ./tuxdeck-*.x86_64.rpm
$ systemctl --user enable --now tuxdeck
$ tar xzf tuxdeck-*-x86_64.tar.gz
$ cd tuxdeck-*-x86_64 && ./install.sh
$ systemctl --user enable --now tuxdeck
  1. Unplug the deck and plug it back in once, so Linux lets TuxDeck talk to it.
  2. Open TuxDeck from your app menu. Your deck already plays music; the rest is yours.

For 64-bit PCs with a distribution from 2022 or newer. Raspberry Pi, NixOS or older systems: build from source.

04 Questions people ask

Is this the official Elgato app?

No. TuxDeck is an independent project written in Rust. It is not affiliated with, endorsed or sponsored by Elgato or Corsair.

Do I need an Elgato account?

No, TuxDeck doesn't sign in anywhere. Plugins from the Elgato Marketplace website install from the downloaded file – unless they're DRM-protected; those only run in the official app.

Will my favourite plugin work?

Plugins written in JavaScript (most of them) run as they are, and so do HTML plugins with a Chromium-based browser installed. Plugins that ship only a Windows or macOS program can't run on Linux – TuxDeck's Linux check tells you before you rely on one.

GNOME, KDE, Hyprland …?

All of them, on Wayland and X11. Hotkeys work out of the box on Hyprland; on GNOME and KDE (Wayland) switch on the optional virtual keyboard – the handbook explains how.

Is it free?

Yes, free and open source under the MIT license. Bug reports and device reports are the best way to help.
